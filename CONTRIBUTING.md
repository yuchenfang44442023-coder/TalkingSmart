# Contributing to TalkingSmart

Thanks for your interest in contributing to TalkingSmart.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yuchenfang444442023-coder/TalkingSmart.git
cd TalkingSmart
```

Install dependencies:

```bash
npm install
```

Create a local environment file:

```text
.env.local
```

Add your own OpenAI API key:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

Run the project:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
## How to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Improving the UI
- Fixing issues
- Submitting pull requests

## Issues

Before starting work, check the existing Issues.

If your idea does not already exist, feel free to create a new issue.

## Pull Requests

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Test your changes
5. Submit a pull request

Please keep pull requests focused on one feature or fix.

## API Keys

Never commit API keys or `.env.local` files.

Use your own API key when testing TalkingSmart.

## Questions

If you have questions, feel free to open an issue.
